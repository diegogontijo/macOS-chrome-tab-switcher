Zen-style Ctrl+Tab for Google Chrome

Make Chrome's Ctrl+Tab switch to your most recently used tab, like Zen Browser and Firefox. Hold Ctrl, tap Tab, release to switch. Free and open source for macOS.

Why Tabber

Chrome's Ctrl+Tab goes to the next tab on the right. Most of the time you want the one you were just on.

Most recently used order

Ctrl+Tab goes back to the tab you just left, not the neighbor on the right.

Hold, browse, release

Keep Ctrl held to walk through recent tabs in an on-screen list. Release to jump.

No flicker

A quick tap just toggles your last two tabs. The list only shows up if you hold.

Works everywhere

On chrome:// pages, the Web Store and New Tab, the list opens in a small popup.

Private by design

No access to all websites, no network requests, no data collected.

Light and dark

The list follows your system appearance, with favicon, title and site.

Shortcuts

Tabs from the current window, same as Zen.

Ctrl+Tab (quick)Toggle with the last used tab
Hold Ctrl, tap Tab Tab…Move down the list (older tabs)
Ctrl+Shift+TabMove up the list
Release CtrlGo to the highlighted tab
Ctrl+EscClose the list without switching

How it works

Chrome doesn't let any extension use Ctrl+Tab. Karabiner-Elements catches it first, only while Chrome is in front, and turns it into internal shortcuts the extension understands.

you press karabiner sends extension ctrl+tab → ctrl+shift+1 → next tab in the list ctrl+shift+tab → ctrl+shift+2 → previous tab in the list release ctrl → ctrl+shift+3 → switch ctrl+esc → ctrl+shift+4 → cancel

Install

About five minutes. Full details in the README.

  1. Install Karabiner-Elements

    Run brew install --cask karabiner-elements or use the official installer, then allow its background items, driver extension and Input Monitoring in System Settings.

  2. Enable the Tabber rule

    Copy karabiner/tabber.json to ~/.config/karabiner/assets/complex_modifications/, then in Karabiner go to Complex Modifications → Add predefined rule → Enable.

  3. Load the extension

    Open chrome://extensions, turn on Developer mode, click Load unpacked and pick the extension folder.

  4. Check the shortcuts

    In chrome://extensions/shortcuts, Tabber should have Ctrl+Shift+1 through 4.

FAQ

How do I make Ctrl+Tab switch to the last used tab in Google Chrome?

Chrome's Ctrl+Tab always goes to the next tab on the right and has no setting to change it. On macOS, Tabber changes that: install Karabiner-Elements, enable the Tabber rule and load the extension. Ctrl+Tab then goes to the tab you used before, in most recently used order.

Can I get Zen Browser's or Firefox's Ctrl+Tab behavior in Chrome?

Yes. Hold Ctrl, tap Tab to move through your recent tabs in an on-screen list, and release Ctrl to switch. It mirrors Firefox's "Ctrl+Tab cycles through tabs in recently used order" option, which Zen Browser uses.

Why can't a Chrome extension use Ctrl+Tab on its own?

Chrome reserves Ctrl+Tab: the chrome.commands API doesn't accept the Tab key and web pages never receive the shortcut. Tabber uses Karabiner-Elements to catch it at the system level, only while Chrome is in front.

How do I switch back to the previous tab in Chrome on a Mac?

With Tabber, a quick Ctrl+Tab toggles between your two most recent tabs, like ⌘+Tab does for apps.

Is this the same as Chrome's tab search?

No. Tab search (⌘+Shift+A) is a searchable list you type into. Tabber is the quick hold-and-release switcher for the tabs you just used.

Does it work on Windows or Linux?

Not yet. The extension is platform independent, but the Ctrl+Tab remap currently ships only as a Karabiner-Elements rule, which is macOS only.

Does it work in Brave, Edge, Arc or other Chromium browsers?

Not tested. The extension should load in Chromium-based browsers, but the Karabiner rule only targets Google Chrome. Adding the browser's bundle identifier to the rule is the starting point.

Does it collect data or need access to all my websites?

No. It makes no network requests and stores nothing. It only uses the tabs, scripting, activeTab and favicon permissions.

Do I need to keep Karabiner-Elements open?

No. You can close its window, even with ⌘+Q. Its background services keep running and start automatically at login.
